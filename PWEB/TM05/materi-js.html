JavaScript dari Nol: Variabel, Fungsi, dan DOM

📖
Catatan Materi

JavaScript (JS) adalah bahasa pemrograman yang membuat halaman web menjadi interaktif dan dinamis. Jika HTML adalah kerangka dan CSS adalah tampilan, maka JavaScript adalah otaknya — ia memproses logika, merespons aksi pengguna, dan memperbarui konten tanpa perlu reload halaman.

  • let / const — Cara mendeklarasikan variabel. Gunakan const jika nilainya tidak berubah, dan let jika bisa berubah. Hindari var di kode modern.
  • Tipe Data — JS mengenal beberapa tipe: String (teks), Number (angka), Boolean (true/false), Array (daftar), dan Object (pasangan key-value).
  • Function — Blok kode yang bisa dipanggil berulang kali. Dua cara menulis: function nama() {} atau arrow function const nama = () => {}.
  • Kondisional — Logika percabangan menggunakan if, else if, dan else untuk mengambil keputusan berdasarkan kondisi tertentu.
  • DOM (Document Object Model) — Representasi HTML sebagai pohon objek. JS bisa mengakses dan mengubah elemen HTML secara langsung. Contoh: document.getElementById('id').
  • Event Listener — Cara JS "mendengar" aksi pengguna seperti klik, hover, atau input. Contoh: element.addEventListener('click', fungsi).
  • Console — Alat debug utama. Gunakan console.log(nilai) untuk melihat output di DevTools browser.
💡
Urutan Belajar yang Tepat: Kuasai HTML dan CSS dulu sebelum masuk ke JavaScript. JS bekerja di atas struktur HTML — kalau fondasinya belum kuat, kode JS kamu akan lebih sulit dipahami.
💻
Contoh Kode

Contoh JavaScript dasar: variabel, fungsi, kondisional, dan manipulasi DOM untuk membuat tombol interaktif:

JavaScript 
// === Variabel ===
const nama = "Budi";          // const: nilai tetap
let skor = 0;                 // let: nilai bisa berubah

// === Fungsi ===
function sapa(pengguna) {
    return `Halo, ${pengguna}! Selamat belajar.`;
}

console.log(sapa(nama));
// Output: "Halo, Budi! Selamat belajar."

// === Kondisional ===
function cekKelulusan(nilai) {
    if (nilai >= 75) {
        return "✅ Lulus!";
    } else if (nilai >= 60) {
        return "⚠️ Hampir lulus, coba lagi.";
    } else {
        return "❌ Belum lulus.";
    }
}

// === Manipulasi DOM ===
const tombol = document.getElementById('tombol-klik');
const output = document.getElementById('output-teks');

tombol.addEventListener('click', function() {
    skor++;
    output.textContent = `Tombol diklik ${skor} kali!`;
    output.style.color = skor >= 5 ? '#1D9E75' : '#D85A30';
});
