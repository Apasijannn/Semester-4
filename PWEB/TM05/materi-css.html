Mempercantik Web dengan CSS: Dari Selector hingga Flexbox

📖
Catatan Materi

CSS (Cascading Style Sheets) adalah bahasa yang mengatur tampilan visual elemen HTML. CSS memisahkan konten (HTML) dari desain visual, sehingga kode lebih rapi dan mudah dikelola.

  • Selector — Menentukan elemen HTML mana yang diberi gaya. Contoh: p (tag), .class (kelas), #id (ID).
  • Property — Aspek tampilan yang ingin diubah. Contoh: color, font-size, margin.
  • Value — Nilai dari properti. Contoh: red, 16px, auto.
  • Box Model — Setiap elemen adalah sebuah kotak dengan lapisan: Content → Padding → Border → Margin.
  • Flexbox — Sistem layout satu dimensi (baris atau kolom). Properti utama: display: flex, justify-content, align-items.
  • CSS Grid — Sistem layout dua dimensi (baris DAN kolom sekaligus). Cocok untuk tata letak halaman yang kompleks.
  • Media Query — Membuat tampilan responsif berdasarkan ukuran layar. Contoh: @media (max-width: 768px) { ... }
💡
"Cascading" dalam CSS berarti aturan diterapkan secara bertingkat. Jika ada konflik, aturan yang lebih spesifik atau yang ditulis terakhir akan menang — ini disebut specificity dan cascade order.
💻
Contoh Kode

Contoh styling lengkap untuk membuat tombol dan kartu sederhana menggunakan Box Model dan Flexbox:

CSS 
/* === Tombol === */
.tombol-keren {
    background-color: #D85A30;
    color: white;
    padding: 12px 24px;       /* padding: atas-bawah kiri-kanan */
    border: none;
    border-radius: 100px;     /* sudut membulat sempurna */
    cursor: pointer;
    font-weight: 600;
    transition: all 0.2s ease;
}

.tombol-keren:hover {
    background-color: #b84a22;
    transform: translateY(-2px); /* geser ke atas 2px */
}

/* === Kartu dengan Flexbox === */
.kartu-container {
    display: flex;
    gap: 20px;
    justify-content: space-between;
    flex-wrap: wrap;          /* wrap ke bawah jika layar kecil */
}

.kartu {
    flex: 1;
    min-width: 200px;
    background-color: #fff;
    border: 1px solid #eee;
    border-radius: 12px;
    padding: 24px;
}

/* === Responsif === */
@media (max-width: 600px) {
    .kartu-container {
        flex-direction: column;
    }
}
