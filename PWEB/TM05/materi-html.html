Pengenalan HTML: Anatomi Tag & Struktur Halaman

📖
Catatan Materi

HTML (HyperText Markup Language) adalah bahasa markup standar untuk membangun struktur halaman web. HTML menggunakan tag — penanda yang membungkus konten dan memberi tahu browser bagaimana menampilkannya.

  • <!DOCTYPE html> — Deklarasi wajib di baris pertama. Memberitahu browser bahwa ini adalah dokumen HTML5.
  • <html lang="id"> — Elemen root yang membungkus seluruh dokumen. Atribut lang menyatakan bahasa konten.
  • <head> — Berisi informasi meta (judul tab, charset, link CSS). Tidak terlihat langsung di layar.
  • <body> — Semua konten yang ditampilkan ke pengguna — teks, gambar, tombol — ada di sini.
  • <h1> – <h6> — Heading dengan hierarki. h1 adalah yang paling penting, gunakan hanya sekali per halaman.
  • <p> — Paragraf. Gunakan untuk setiap blok teks yang berdiri sendiri.
  • <a href="..."> — Anchor/tautan. Atribut href menentukan tujuan link.
  • <img src="..." alt="..."> — Menyisipkan gambar. Atribut alt wajib diisi untuk aksesibilitas.
💡
Tip Penting: HTML bukan bahasa pemrograman — ia tidak punya logika atau kalkulasi. HTML hanya mendefinisikan struktur dan makna konten. Tampilan visual adalah urusan CSS.
💻
Contoh Kode

Struktur lengkap file index.html yang benar dan siap pakai:

HTML 
<!DOCTYPE html>
<html lang="id">

<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Website Pertamaku</title>
    <link rel="stylesheet" href="style.css">
</head>

<body>

    <h1>Halo, Dunia!</h1>
    <p>Ini adalah <strong>paragraf pertama</strong> saya.</p>

    <a href="https://google.com">Kunjungi Google</a>

    <img src="foto.jpg" alt="Foto profil saya">

</body>

</html>
