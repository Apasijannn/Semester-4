Neural Monte Carlo Denoising

Mengatasi noise pada path tracing melalui arsitektur Kernel-Splatting Network

Akar Masalah: Path Tracing Noise

Keterbatasan Monte Carlo

Path tracing menghasilkan gambar fotorealistik, tetapi sangat rentan terhadap *noise* struktural[cite: 171].

  • Dibutuhkan ribuan sampel per piksel (spp) untuk mencapai konvergensi visual.
  • Evaluasi pada 8 hingga 40 spp menghasilkan visual yang tidak dapat digunakan secara produksi[cite: 172, 173].
  • Target *ground truth* seringkali membutuhkan hingga 1000 spp atau lebih[cite: 175].

Dampak Komputasi

Memaksa *renderer* memproses 8192 spp menguras kapabilitas komputasi dan mematikan potensi *real-time rendering*[cite: 200].

Paradigma Denoising Modern

Integrasi Wajib

Denoising bukan lagi sekadar *post-processing* opsional, melainkan komponen esensial yang sangat diperlukan dalam arsitektur *renderer* modern di industri film dan animasi[cite: 179].

Fungsi Objektif Dasar

Ide dasarnya adalah melatih *neural networks* pada dataset berpasangan yang berisi gambar *noisy* sebagai input dan gambar bersih sebagai target[cite: 176, 177].

// Pipeline Klasik
Render(8_spp) -> Output_Noisy;
CNN_Filter(Output_Noisy) -> Output_Clean;

// Masalah:
// Kurang akurat pada tepi geometri kompleks.

Evolusi: Kernel-Splatting Network

Bergeser dari pemetaan sederhana antar gambar (image-to-image), riset terbaru memetakan jalur cahaya (*light paths*) secara langsung ke dalam gambar[cite: 189, 196].

Metodologi Baru

Pendekatan berbasis sampel (*Sample-based Monte Carlo Denoising*) menggunakan *Kernel-Splatting Network*[cite: 190].

Model ini mendistribusikan kontribusi sampel secara cerdas berdasarkan fitur geometri dan metrik kedalaman pencahayaan.

Keunggulan Arsitektur

  • Menghindari artefak blur yang sering terjadi pada konvolusi tradisional.
  • Memproses korelasi gambar hasil *render* menggunakan *recurrent transformers*[cite: 185, 186].
  • Mempertahankan detail bayangan dan refleksi frekuensi tinggi.

Evaluasi Metrik & Performa

Pengujian dilakukan pada input 8 spp dibandingkan dengan referensi absolut (*ground truth*) 8192 spp[cite: 199, 200].
